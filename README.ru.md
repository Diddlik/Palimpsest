# Palimpsest

Palimpsest — это Windows-утилита для тех, кто часто печатает на нескольких
раскладках. Программа должна замечать, что слово набрано в неправильной
раскладке, удалять ошибочные символы, переключать раскладку Windows и заново
вводить правильный текст.

Идея похожа на Punto Switcher, Mahou и Caramba Switcher, но этот проект сделан
как локальная утилита на Rust с упором на низкую задержку обработки клавиатуры,
приватность и предсказуемое поведение при исправлении.

> Состояние разработки: функционально готовая предварительная версия; остаются
> интерактивная проверка и подписанный релиз. Весь конвейер реализован — hook,
> переинтерпретация, оценка, автоматическое исправление, учёт контекста,
> Tauri-интерфейс в трее и installer NSIS. Осталось то, что требует человека:
> проверка на реальном рабочем столе, code signing и soak/perf-тесты.

## Что делает Palimpsest

Palimpsest локально наблюдает за нажатиями клавиш и пытается распознать слова,
набранные не в той раскладке. Например, если пользователь хотел набрать русское
слово, но активной осталась английская раскладка, `ghbdtn` может быть распознано
как `привет`.

Планируемый сценарий коррекции:

1. Наблюдать физические нажатия клавиш через низкоуровневый hook Windows.
2. Собирать слово до разделителя: пробел, Enter, Tab, пунктуация.
3. Переинтерпретировать scan code нажатых клавиш в разных раскладках.
4. Оценить варианты с помощью языковых эвристик.
5. Если другая раскладка явно лучше, отправить Backspace, переключить раскладку
   ОС и ввести исправленный текст.

Первая версия ориентирована на алфавитные пары раскладок, прежде всего EN/RU и
позже EN/DE. Сложные IME-сценарии не входят в первую цель.

## Зачем он нужен

При работе с несколькими языками легко забыть переключить раскладку и получить
на экране набор бессмысленных символов. Palimpsest должен исправлять такие
ошибки локально: без отправки текста на сервер, без сохранения набранного текста
и без задержек при обычной печати.

Проект специально выбирает осторожное поведение. Лучше пропустить сомнительное
исправление, чем ошибочно заменить правильный текст. Поэтому в интерфейсе есть
настройка чувствительности, список исключений, пауза и быстрое откатывание
последнего исправления.

## Как это работает

Главное архитектурное ограничение: callback клавиатурного hook должен быть
максимально коротким. Если он работает слишком долго, Windows может молча
удалить hook. Поэтому Palimpsest разделяет работу на несколько потоков:

- Поток hook: владеет `WH_KEYBOARD_LL`, считывает только virtual key, scan code,
  флаги и время события, отправляет маленькое событие в канал и сразу передает
  управление дальше.
- Поток engine: собирает слова, переинтерпретирует раскладки, считает оценки,
  принимает решение об исправлении, учитывает активное окно и выполняет ввод.
- Поток UI: Tauri 2 интерфейс с tray-иконкой, окном настроек, командами
  конфигурации и событиями статуса.

Синтетический ввод помечается специальным значением `dwExtraInfo`, чтобы
Palimpsest отличал собственные нажатия от пользовательских. Это защищает от
бесконечного цикла, когда программа исправляет текст, который сама же ввела.

## Текущее состояние

Уже реализовано:

- Cargo workspace с `palimpsest-core` (engine) и `palimpsest-app` (Tauri).
- Низкоуровневый keyboard hook Windows с маркировкой `dwExtraInfo`, чтобы
  игнорировать собственный синтетический ввод (без петли обратной связи).
- Трёхпоточный runtime (hook / engine / UI) с чистым запуском и остановкой и
  глобальным переключателем вкл/выкл.
- Модуль word buffer с обработкой границ слова и Backspace.
- Переинтерпретация scan code через `ToUnicodeEx` по настроенным раскладкам.
- Bigram-оценка по языкам (EN, RU, DE) с порогом для разных алфавитов и
  ограничителями, зависящими от чувствительности.
- Автоматическое исправление при печати (Backspace → смена раскладки → Unicode
  retype одним атомарным вводом).
- Три горячие клавиши, по умолчанию сочетания с Ctrl+Shift: преобразовать слово,
  которое вы набираете, или предыдущее — то, что стоит перед курсором (F9),
  преобразовать выделение (F8) и отменить последнее исправление, не отрываясь от
  набора (F10).
- Контекст активного окна: список исключений (терминалы/IDE/игры) и best-effort
  определение нативных полей пароля.
- Tauri 2 tray и окно настроек, разложенное на вкладки — «Общие», «Раскладки»,
  «Сочетания», «История», «О программе»: включение/пауза, чувствительность, пары
  раскладок, список исключений, autostart, горячие клавиши, история и undo.
- Необязательный дневник набора, по умолчанию выключенный: журнал нажатий (и, по
  желанию, буфера обмена), сгруппированный по дням, с поиском и экспортом, с
  возможностью зашифровать паролем (см. «Приватность»).
- Полностью локализованный интерфейс — английский, русский, украинский и
  немецкий — по умолчанию следует языку интерфейса Windows, а в настройках можно
  выбрать конкретный.
- Сериализуемая конфигурация в `%APPDATA%`, применяется на лету (без рестарта).
- Логи диагностики (без набранного текста на уровне по умолчанию), panic hook и
  per-user installer NSIS.
- Подписанное автообновление внутри приложения (Настройки → Updates), которое
  питается сборкой по тегу в GitHub Actions.

Осталось до публичного релиза (требует человека):

- Интерактивная проверка в реальной сессии Windows.
- Code signing сертификатом OV/EV и allow-listing у антивирусов.
- Многодневное soak-тестирование и профилирование горячего пути.

## Приватность и безопасность

Palimpsest — полностью локальная программа:

- Набранный текст не отправляется в сеть — никогда и ни при каких настройках.
- Буфер слова короткий и хранится только в памяти.
- Диагностические логи не содержат набранный текст на уровне по умолчанию.
- Единственный сетевой запрос — проверка обновлений: обычная загрузка ленты
  релизов, без идентификаторов и телеметрии. Пакет обновления проверяется по
  ключу подписи, вшитому в приложение, поэтому взломанный хост загрузок не
  сможет подсунуть свой код.

Набранный текст на диск пишут ровно две функции. Больше ничего этого не делает,
обе лежат в `%APPDATA%\com.palimpsest.desktop\` каждая в своём файле, и обе
можно посмотреть и стереть в разделе Настройки → История:

- **Выученные слова** (`user_words.json`) — по умолчанию **включено**. Отмена
  исправления говорит Palimpsest, что слово было набрано правильно, и
  единственный способ не исправлять его завтра — записать его. Одно слово на одну
  отмену, ничего больше.
- **Дневник набора** (`diary.json`, отдельная вкладка) — по умолчанию
  **выключен**, и обновление программы его не включает. Это именно журнал нажатий,
  как «дневник» Punto Switcher: включите — и каждое набранное слово будет
  записываться с разбивкой по приложениям и по дням, с поиском и экспортом, а не
  только исправления. Может записывать и буфер обмена (отдельная настройка). Он
  действительно помогает восстановить текст, съеденный упавшим приложением, но о
  компромиссе стоит сказать прямо: прочитать дневник сможет любой, у кого есть
  доступ к вашему профилю, — **если не задать пароль дневника**, который шифрует
  файл (Argon2id + XChaCha20-Poly1305). Защищённый дневник загружается
  заблокированным и не показывается и не пишется, пока его не разблокируют, а
  забытый пароль восстановить нельзя. В полях паролей и в приложениях-исключениях
  ничего не записывается, записи короче двух слов по умолчанию пропускаются,
  а один клик стирает всё. Хранение можно ограничить числом записей, возрастом
  и размером файла; по умолчанию сохраняется до 500 записей.

Так как программа использует глобальный keyboard hook и синтетический ввод,
антивирусы и SmartScreen могут воспринимать ее подозрительно. Для нормального
релиза нужны code signing, прозрачное поведение, отсутствие обфускации и понятная
документация.

Ограничения безопасности Windows остаются в силе. Не повышенный процесс
Palimpsest не сможет надежно вводить текст в окна администратора, UAC prompt,
экран блокировки или secure desktop. Необязательная настройка **Всегда запускать
от имени администратора** использует одну задачу планировщика, подтверждённую
через UAC, и сохраняет повышение при входе, ручном запуске и перезапуске после
обновления.

## Интерфейс

Настольное приложение на Tauri 2:

- Tray-иконка со статусом вкл/пауза: левый клик переключает, правый открывает
  меню (Enabled, Settings, Open logs folder, Quit).
- Окно настроек из шести вкладок — **Общие** (чувствительность, язык, autostart,
  логи, обновления), **Раскладки** (пары раскладок, список исключений),
  **Сочетания**, **История** (исправления, выученные слова), **Дневник**
  (необязательный дневник набора) и **О программе**; изменения применяются на
  лету, без рестарта.
- История исправлений и undo последнего исправления, в том числе по горячей
  клавише.
- Живые status- и correction-события от engine.

Приложение работает в единственном экземпляре (hook ставится только один раз) и
живёт в трее; закрытие окна настроек прячет его, а не завершает программу.

### Язык интерфейса

Окно настроек и меню в трее доступны на английском, русском, украинском и
немецком. По умолчанию выбран вариант **Язык системы**: он следует языку
интерфейса Windows, а для остальных языков откатывается к английскому. В разделе
Настройки → Язык можно закрепить конкретный. Это только оформление — набор
языков, которые Palimpsest *исправляет*, определяется парами раскладок.

## Сборка и разработка

Требования:

- Windows.
- Rust stable toolchain для `x86_64-pc-windows-msvc`.
- Tauri CLI (`cargo install tauri-cli --version "^2"`) — только для сборки
  installer; обычный `cargo run` работает и без неё.

Сборка workspace и проверки:

```powershell
cargo build --workspace --examples
cargo test --workspace
cargo clippy --workspace --examples
```

Запуск приложения (tray + настройки):

```powershell
cargo run -p palimpsest-app
```

Сборка installer (NSIS, per-user):

```powershell
cd crates/palimpsest-app
cargo tauri build
# → target/release/bundle/nsis/Palimpsest_<version>_x64-setup.exe
```

Релизы собирает GitHub Actions по тегу, и workflow не примет тег, который
расходится с манифестами. `scripts/bump.ps1` поднимает версию сразу в
`Cargo.toml`, `crates/palimpsest-app/tauri.conf.json` и `Cargo.lock`, делает
коммит, ставит тег и пушит:

```powershell
./scripts/bump.ps1                 # patch: 0.3.0 -> 0.3.1, тег, push
./scripts/bump.ps1 -Part minor     # 0.3.0 -> 0.4.0
./scripts/bump.ps1 -Version 1.0.0  # явная версия
./scripts/bump.ps1 -DryRun         # показать план, ничего не менять
```

Это опубликует installer и подписанную ленту `latest.json`, которую читает
встроенное автообновление.

Интерактивные spikes для ядра — запускать вручную в локальной Windows-сессии
(они наблюдают или вводят данные в активное окно):

```powershell
cargo run -p palimpsest-core --example spike_hook
cargo run -p palimpsest-core --example spike_correct  # ghbdtn -> привет в Notepad
cargo run -p palimpsest-core --example spike_context
```

Подробности о подписи, антивирусах, логах и релизе — в `plan/DISTRIBUTION.md`,
детальный статус — в `plan/PROGRESS.md`.
