Layout pairs

Pairs are considered in both directions. Palimpsest reinterprets a word across these layouts and switches to the better one.

Ignore in these apps

Palimpsest stays completely silent in these — terminals, IDEs, games. Pick one from your running apps, or type executable names (one per line, e.g. cmd.exe).

Click “Set hotkey”, then press a combination. Default Ctrl+Shift+F9. On laptops and 75% keyboards prefer a chord — keys like Pause or Scroll Lock often aren't there. Converts the word you are typing, or the one just behind the caret. Esc cancels.

Select any text, then press this to retype it in the other layout (e.g. “ghbdtn” → “привет”). Default Ctrl+Shift+F8; a modifier chord works on every keyboard. Esc cancels.

Reverts the last correction without leaving what you are typing — the same as “Undo last” below. Default Ctrl+Shift+F10. Esc cancels.

Learned words

Undoing a correction tells Palimpsest the word was right as typed, so it stops correcting it. Stored locally in user_words.json, never sent anywhere. Turn the setting off to save nothing at all.

Typing diary

This is a keystroke log. With it on, every word you type is written to diary.json on this machine — not just corrections. Anyone with access to your user profile can read it. Nothing is recorded in password fields or ignored apps, nothing is ever sent anywhere, and it is off unless you switch it on here.

Palimpsest

—

Palimpsest watches for a word typed in the wrong keyboard layout, erases it, switches the layout, and retypes what you meant. Everything happens on this machine.
